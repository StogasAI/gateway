# Stogas structured PII redaction

This package is a fixed step in the Stogas request path. It has no loader, manifest, activation control, external service, or retained replacement map.

It scans accepted Chat Completions and Responses text containers, including stop sequences, before token estimation and provider conversion. It uses typed irreversible placeholders for high-confidence email addresses, formatted phone numbers, payment and bank identifiers, checksum-valid national identifiers, credentials, private keys, and vendor token formats. Context is required for ambiguous number formats. The default excludes names, street addresses, locations, IP addresses, UUIDs, ordinary dates, and unformatted numbers to limit false positives. Provider-signed Chat reasoning details and top-level encrypted Responses reasoning items are preserved only in their accepted replay locations.

The internal policy API accepts an explicit list of `email_address`, `phone_number`, `social_security_number`, `credit_card_number`, `ip_address`, `credentials`, `private_keys`, `json_web_tokens`, `database_urls`, `vendor_tokens`, `bank_identifiers`, `national_identifiers`, and `health_identifiers`. There are no presets. `credentials` covers named password, secret, API-key, access-key, and token assignments; Basic and Bearer credentials; and credentials in HTTP, HTTPS, FTP, FTPS, and SFTP URLs. `private_keys` covers PKCS #8, RSA, EC, DSA, OpenSSH, and PGP blocks. `database_urls` covers PostgreSQL, CockroachDB, MySQL, MariaDB, MongoDB, SQL Server, Redis, and AMQP credentials. `vendor_tokens` covers the exact local inventory for AWS and Bedrock, GitHub, GitLab, Google, Slack, Anthropic, OpenAI, Stripe, Hugging Face, Groq, npm, PyPI, Doppler, 1Password, PlanetScale, Pulumi, Sentry, Vault, Databricks, DigitalOcean, Perplexity, Twilio, Shopify, Linear, Atlassian, age, SendGrid, Telegram, and Notion token forms.

`bank_identifiers` covers IBAN and U.S. routing numbers. `national_identifiers` covers U.S. ITIN, U.K. NINO, Canadian SIN, Australian TFN/ABN/ACN, Indian Aadhaar, Brazilian CPF/CNPJ, Spanish DNI/NIE, Italian fiscal and VAT identifiers, Polish PESEL, Korean resident and business identifiers, and supported Finnish, Thai, Singaporean, Chinese, Israeli, South African, Turkish, German, Swedish, and Nigerian identifiers. `health_identifiers` covers U.K. NHS, Australian Medicare, U.S. NPI and Medicare, and German health-insurance identifiers. Strict IPv4 and IPv6 parsing is available through `ip_address`.

Custom patterns use one bounded, leftmost-longest RE2 matcher, a fixed `<CUSTOM_PII>` replacement, and limits of 16 expressions, 512 bytes per expression, 4,096 total expression bytes, 4,096 compiled instructions, and the normal request match cap. Empty, zero-width, invalid, overly complex, and placeholder-matching expressions are rejected without returning the expression in the error. This API is not connected to a request header or user control. Person names and street addresses are not options because reliable detection needs a separately measured contextual detector.

The clean path returns the original bytes. Work, nesting, and match counts are bounded. When the plugin runs for a logged request, the log contains `plugins.stogas_structured_pii_redaction.items_redacted` and `duration_us`. Synthetic logs that cannot prove execution omit the entry. Source values, hashes, offsets, replacement maps, and per-category counts are never logged. Category counts would reveal facts about prompt contents outside the guest.

The independent Go implementation and its positive and negative tests were checked against the Apache-2.0 [Microsoft Presidio](https://github.com/microsoft/presidio/tree/eb93051b60b7daa44b4b8b1acdcce60522bacc8a) and [Censgate redact](https://github.com/censgate/redact/tree/f45c45ccaab17b2c1801a64b4c67cc5cf7188a5e) recognizer corpora; the MIT-licensed [Gitleaks](https://github.com/gitleaks/gitleaks/tree/b58d3f102cf3a2c84cb7f923d05c25c9b1aed84b), [detect-secrets](https://github.com/Yelp/detect-secrets/tree/5e141933554a0b74e7341841f318be21e895339c), and [Braintree card-type](https://github.com/braintree/credit-card-type/tree/fbd8ed80a411fa9b238055208c19a7323cd38e21) corpora; [Google libphonenumber](https://github.com/google/libphonenumber/tree/dba03901d523cc358310859a3d3c34d11b92f0bf) calling codes; and the [SWIFT IBAN Registry release 101](https://www.swift.com/sites/default/files/files/iban-registry-v101.pdf). No source code was imported.
